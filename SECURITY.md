# Security policy

Report a vulnerability in LibreDB Platform or its installer privately, never in a public issue, pull request or discussion.
Use GitHub's private vulnerability reporting on this repository, under Security, Report a vulnerability, or write to [info@libredb.org](mailto:info@libredb.org).
Name the affected version, the steps that reproduce the problem and what an attacker gains.

The supported version is 1.0.x.

LibreDB Studio has its own repository and its own [security policy](https://github.com/libredb/libredb-studio/blob/main/SECURITY.md), so report a vulnerability in Studio there.
