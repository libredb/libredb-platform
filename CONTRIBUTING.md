# Contributing

LibreDB Platform is source-available under the [Elastic License 2.0](LICENSE), and Sekoya Tech develops it.
We do not accept pull requests from outside the team at this time, so that Sekoya Tech keeps the right to license all of the code.
A pull request from outside the team is closed without being merged; open an issue instead, and we will consider the change.

Issues are welcome: report a bug or ask a question in [GitHub Issues](https://github.com/libredb/libredb-platform/issues).
Report a vulnerability as [SECURITY.md](SECURITY.md) describes, never in a public issue.
For licensing, write to info@libredb.org.

LibreDB Studio is open source in its own repository, [libredb/libredb-studio](https://github.com/libredb/libredb-studio), with its own contribution rules.
When this project starts to accept contributions, this file will say how, and under which contributor agreement.
